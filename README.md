# Ria Writes

A responsive, single-page personal journal website built with plain HTML, CSS and JavaScript. No build tools or frameworks are required.

## Preview locally

Open `index.html` in a browser. Internet access is used for Google Fonts and the Unsplash photos.

## Publish with GitHub Pages

1. Create a GitHub repository, for example `ria-writes`.
2. Upload `index.html`, `styles.css`, `script.js`, and this `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. GitHub will show the published website link in the Pages section after deployment finishes.

## Before launch

- Replace the sample posts, photos, About copy, and contact email with your own.
- The newsletter form is a visual demo only. Connect it to a mailing-list service before collecting subscriptions.
- Use your own or properly licensed photos for a public site.
